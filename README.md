☀️ スマート単軸ソーラートラッキングシステム (Smart Single-Axis Solar Tracking System)
📌 プロジェクト概要 (Overview)太陽光の動きを自律的に追跡してエネルギー収集効率を最大化し、iOSアプリを通じてリアルタイム監視・制御を行うハイブリッド電源システムです 。
組み込みファームウェア(C言語)とモバイルアプリ(Swift)を連携させ、ハードウェアの物理的制約やノイズをソフトウェアアルゴリズムで克服することに注力しました。  
🛠 技術スタック (Tech Stack)Firmware: C, ATmega128   Software (iOS): Swift, CoreBluetooth   Hardware/Sensors: MG996R(Servo), GM7537(CDS), DS3231(RTC), HM-10(BLE), 2-Channel Relay, P-MOSFET   Communication: I2C, UART   
✨ コア実装とトラブルシューティング (Key Features & Troubleshooting)
1. ソフトウェアによるハイブリッド電源の安全制御 (Break-Before-Make)課題: バッテリーとアダプター電源の切り替え時、両方が同時にオンになるとショートが発生し、回路が破損する危険性がありました 。  解決: スイッチング時に「すべての電源を完全にオフにしてから（大気電力ゼロ状態）、次の電源をオンにする」という Break-Before-Make アルゴリズムをC言語で実装しました 。また、切り替えの間に delay_ms を挟むことで、リレーの機械的なアーク（火花）を防止し、システムの安定性を極大化しました 。
2. センサーノイズのフィルタリングと比例制御によるハンティング防止課題: 雲や鳥の影など、微細な光の変化にモーターが過敏に反応し、無駄な電力消費とハンティング現象（モーターの震え）が発生しました。解決: * デッドゾーン (Dead-Band): 誤差が一定値(150)以下の場合は微細な変化とみなし、あえてモーターを動かさないロジックを実装しました 。  比例制御: 誤差の大きさに応じてモーターの可変幅をスケール（1/12）し、目標値に近い場合は滑らかに停止するよう制御しました 。
3. I2C通信におけるノイズマスキング (Bit Masking)課題: リレースイッチング時に発生する逆起電力（ノイズ）がI2C通信ラインに混入し、DS3231(RTCモジュール)から読み取る時間データが破損する問題に直面しました 。  解決: 通信データのうち、時間データ以外の不要なビット（ノイズで1に反転したゴミ値）を切り捨てるために、ビットマスキング（& 0x7F, & 0x3F）を適用しました 。さらに、読み取った時間が「0~23時、0~59分」という常識的な範囲内にある場合のみシステムに反映させる二重の条件分岐を設け、アプリ側には常に正確な時間のみが同期されるよう工夫しました 。  4. SwiftによるBLE連携と専用ダッシュボードiOSのCoreBluetoothフレームワークを利用し、HM-10モジュール(UART)と通信するアプリを独自に設計しました 。ハードウェア側で取得した電圧ADC値や現在の電源状態をリアルタイムで受信し、直感的なダッシュボードとして可視化しています 。  


💡 学んだこと・アピールポイント本プロジェクトを通じて、単にハードウェアを組み立ててコードを書くだけではなく、「ハードウェアの特性（リレーの物理的遅延や逆起電力など）を深く理解した上で、それをソフトウェアでいかに安全かつ効率的に制御するか」という、エンジニアとしての本質的な課題解決能力を養うことができました。
